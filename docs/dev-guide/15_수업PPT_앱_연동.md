# 15. 수업 PPT ↔ 앱 연동 — 차시 PPT 를 받아 앱을 만들고 PPT 에 넣는 순서

> 2026-10-07, **t02 알티노 걸음마 가르치기**(Canva 60쪽)를 처음 끝까지 해 보고 정리했다.
> 남은 14개 차시도 **PPT 가 먼저 오고 → 앱을 만들고 → PPT 를 앱에 맞게 고친다.** 이 순서를 그대로 따른다.

## 1. 큰 순서

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| ① PPT 읽기 | 쪽마다 활동·발문·규칙을 적는다. 오타·넘치는 글·틀린 개념부터 고친다 | 고친 PPT |
| ② 앱 자리 정하기 | 앱이 들어갈 **활동**을 고른다(보통 2~3개). 앱이 하는 일과 사람이 하는 일을 나눈다 | 결정 목록 (§2) |
| ③ 앱 만들기 | `t00` 복사 → 단계 탭 이름 = **PPT 활동 이름 그대로** | `webapp/tNN.*`, `tests/tNN.mjs` |
| ④ 기획서 | `docs/topics/tNN.md` — PPT 쪽 번호와 앱 단계를 같이 적는다 | 기획서 |
| ⑤ 화면 캡처 | PPT 에 넣을 화면을 찍는다 (§3) | `docs/topics/tNN_화면/*.png` |
| ⑥ PPT 고치기 | 앱 여는 쪽·조작 쪽·활동별 '앱으로 ~' 쪽, 발표자 노트 (§4) | 고친 Canva |
| ⑦ 합치기 | PR → main → 웹·APK 자동 배포 (06 §5) | |

## 2. 앱 자리를 정할 때 — 먼저 물어볼 것

PPT 활동마다 아래를 정하고 나서 만든다. 정하지 않고 만들면 PPT 와 앱이 따로 논다.

- **무엇을 앱이 하고, 무엇을 사람이 하나** — 사람이 하기 어렵고 공정해야 하는 것(시간 재기, 기록 저장)은 앱이,
  센서가 없는 것(줄자로 재는 거리, 선 넘었는지)은 사람이 보고 앱에 ⭕/❌ 로 넣는다.
- **PPT 에 있어도 앱에 안 넣을 것** — 예: t02 의 '속도 200 탐구'는 넣지 않기로 했다(250 미만은 출발 불가 03 §1).
- **규칙을 앱이 지켜 주게** — "버튼은 한 번만", "예상을 먼저 적고 잠그기"처럼 PPT 의 규칙은 앱이 막아 준다.
- **역할(조종사·신호원·기록원)** — 누가 태블릿을 쥐는지. 기록원이 누르는 버튼은 크게.

t02 에서 정한 것 (예시):

| PPT 활동 | 앱 단계 | 앱이 하는 일 | 사람이 하는 일 |
|---|---|---|---|
| 걸음마 연습 (앱 조작 12~19쪽) | ① 걸음마 연습 | 누르는 동안만 움직이는 패드, 속도 막대, 구령 카드, 2분 역할 타이머 | 구령 외치기, 역할 바꾸기 |
| 속도의 비밀 찾기 (21·25쪽) | ② 속도의 비밀 찾기 | 예상 잠금, **정확히 3초 달리기**, 예상·실제 막대그래프 | 뼘으로 실제 거리 재서 입력 |
| 걸음마 시험 (45·46쪽) | ③ 걸음마 시험 | 앞으로 버튼 한 번 규칙, 3번 중 2번 판정, 성장기록부 | **기록원이 줄자로** 정지선 앞뒤 10cm 판정 → ⭕/❌ |

## 3. 화면 캡처 — PPT 에 넣을 그림

- 가짜 로봇(브라우저)으로 앱을 열고 1280×800 으로 찍는다. 버튼 하나를 설명하는 쪽은 그 버튼만 **확대**(Canva 에서 자르기).
- 저장 위치: `docs/topics/tNN_화면/` — 이름은 무엇인지 알 수 있게(`d-up.png`, `step2.png`, `speed500.png`).
- t02 에서 찍은 것: 학교 화면, 연결 화면, 패드 네 방향, 속도 막대, 속도 300/500, 단계 ①②③.

## 4. Canva 고치기 규칙

**넣는 쪽** (t02 기준, 다른 차시도 같은 자리에):

| 자리 | 쪽 | 내용 |
|---|---|---|
| 도입 끝 (t02: 10·11쪽) | 앱 열기 · 연결하기 | 로봇학교 화면 → 내 차시 누르기 / 상단 🔗 로 내 알티노 연결 |
| 조작을 처음 배우는 곳 (12~17쪽) | 버튼마다 한 쪽 | 확대 캡처 + 한 줄 설명 |
| 활동마다 (25·46쪽, 새로 만듦) | **'앱으로 ~' 쪽 1장** | 그 단계의 순서를 3~4칸으로 (예: 예상 잠그기 → 3초 달리기 → 실제 기록) |
| 역할 안내 쪽 (45쪽) | 문구만 | "기록원이 앱에서 ⭕, ❌를 눌러요"처럼 앱 버튼 이름을 그대로 |

- **버튼·단계 이름은 앱 화면 글자와 똑같이** 쓴다. PPT 와 앱이 다르게 부르면 학생이 헷갈린다.
- 바꾼 쪽은 **발표자 노트도** 앱 쓰는 법에 맞게 고친다.
- **소스 페이지(t02 덱 56~60쪽: 캐릭터·숫자 소스)는 지우거나 숨기지 않는다** — 다른 차시를 이걸로 만든다.
- 글이 상자를 넘치면 문장을 줄인다(글자 크기를 줄이지 않는다). 겹친 그림·너무 작은 그림은 지운다.
- 모든 수정은 한 번에 모아 보여 주고, **확인을 받은 뒤 저장**한다.

**이미지 올리기**: Canva 는 URL 로 이미지를 받는다. 저장소가 공개라서 GitHub 의 원본 주소
(`https://raw.githubusercontent.com/i20091119-ai/2026.-altinoneoschool/<브랜치>/docs/topics/tNN_화면/<파일>.png`)를 주면 된다.
캡처를 먼저 푸시한 뒤 올린다.
