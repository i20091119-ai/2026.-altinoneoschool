# t01 로봇학교 입학식 · 첫 만남

> 상태: **검토중** · 저자: 이상우(A) · 검토: 다른 저자 1명 검토 후 `확정`
> 수업 내용은 저자 확정(2026-10-20). 수업 PPT(Canva)는 이 앱을 기준으로 새로 만든다(15 문서 순서를 거꾸로: 앱 → PPT).

## 1. 기본 정보

| 차시 | 반 | 연결 교과 | 로봇·센서 |
|---|---|---|---|
| 1–2 | 입학하기 | 국어[4국01-06] | 알티노 (도트매트릭스·부저 신호) |

**시간표 활동**: 전학 온 로봇 학생 알티노를 만나 전원 켜기와 블루투스 연결을 익히고 모둠 알티노의 이름 짓기 / 조종하기로 첫 주행을 해 보고 성장기록부를 받아 알티노가 지금 할 수 있는 것과 없는 것을 관찰하기

**서사 장치**: 알티노의 부탁 편지 **No.0** 「전학 왔어요. 그런데 저는 아무것도 할 줄 몰라요.」 — t02 의 No.1 로 이어진다.

## 2. 배움 목표
- 알티노의 전원을 켜고 바닥 스티커 번호로 태블릿과 연결할 수 있다.
- 이름 후보와 그 까닭을 말하고, 모둠의 의견을 모아 알티노의 이름을 정할 수 있다. (국어[4국01-06])
- 조종 패드로 알티노를 움직여 보고, 지금 할 수 있는 것과 아직 못 하는 것을 구분할 수 있다.

## 5. 화면 흐름
- 단계 표시 `① 알티노 깨우기 ② 이름 지어 주기 ③ 첫 주행과 관찰` — 언제든 눌러 이동, 지금 단계는 mint. 단계를 바꾸면 누르던 패드·자율 동작을 멈춘다.
- ① 알티노 깨우기: 왼쪽 할 일 3줄(1 전원 켜기 `켰어요` · 2 연결하기 `🔗 연결하기` · 3 깨우기) — 연결되면 1·2가 자동으로 완료. `👋 알티노 깨우기`는 연결돼야 켜진다. 오른쪽은 로봇 도트와 같은 8×8 얼굴 미리보기.
- ② 이름 지어 주기: 왼쪽 약속 3줄 + 후보 입력 `후보 올리기`(4개까지, 같은 후보 안 됨, ✕ 로 지움). 후보를 누르면 고름 → 오른쪽 `이 이름으로 정하기` → 확인창 → 이름표·상단 👥 에 표시. 이미 이름이 있으면 `이 이름으로 바꾸기`.
- ③ 첫 주행과 관찰: 왼쪽 패드(속도 300). 오른쪽 카드 6개 — 🚗 앞뒤로 움직이기(▲·▼를 둘 다 써 봐야 ✓) / 🎯 정지선에 딱 멈추기 3–4차시 · 🙂 표정 짓기 5–6차시 · 🎵 노래하기 7–8차시 · 💡 신호 보내기 9–10차시 · ✋ 손 따라오기 11–12차시(누르면 🔒 배울 차시 표시). 아래 `아직 못 하는 것 n / 5`.
- 다섯 개를 다 찾고, 앞뒤로 움직여 봤고, 이름이 있으면 `🎒 입학 약속하기` 가 켜진다 → 약속 창(세 약속을 다 눌러야 `입학하기`) → 성장기록부 한 줄, 버튼은 `✔ 입학했어요`.
- `처음부터`(확인창): 이 앱 저장만 지움. 모둠 이름·성장기록부는 남긴다.

## 6. 성공 판정과 성장기록부
- 성공 판정: 깨우기 1회 + 이름 정하기 1회 + ▲·▼ 주행 각 1회 이상 + 아직 못 하는 것 **5 / 5** 찾기 + 약속 **3 / 3** = 입학. 평가가 아니라 출발점 기록이라 별은 주지 않는다(t15 졸업식에는 ✔ 로 보인다).
- `kit.record.add({ title: '로봇학교에 입학했어요', detail: '씽씽이와 함께 · 가르쳐 줄 것 5가지를 찾았어요', stars: 0 })` — 이 앱 기록이 이미 있으면 다시 남기지 않는다.
