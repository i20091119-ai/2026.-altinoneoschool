## 2. 배움 목표
- 블록을 순서대로 놓아 출발점에서 도착점까지 가는 길을 알티노에게 안내할 수 있다.
- 되풀이되는 블록 묶음을 찾아 수로 나타낼 수 있다(예: '↑ ↑ →' 가 2번).
- 알티노의 움직임과 블록을 비교해 틀린 순서(버그)를 찾아 고칠 수 있다.

## 5. 화면 흐름
- 단계 표시 `① 사람 로봇 놀이 ② 블록으로 길 안내하기 ③ 버그 고치기 미션` — 단계를 바꾸면 실행을 멈춘다.
- 격자 지도: 가로 5칸 × 세로 4칸, 출발(아래 둘째 칸)에서 위를 보고 시작. 기호 `↑ 앞으로 한 칸 · ← 왼쪽으로 돌기 · → 오른쪽으로 돌기`(활동지와 같음).
- 블록 편집(①②③ 같음): 팔레트를 누르면 고른 블록 뒤에(없으면 맨 뒤) 끼움, 블록을 누르면 고르기 → `빼기`·`◀ 옮기기`·`옮기기 ▶`·`모두 지우기`(확인창). 12개까지.
- ① `🚩 도착점까지`/`💎 보물 칸까지` → 카드 놓기 → `📣 한 장씩 읽기`(지도에서 한 칸씩, `notice`) → 다 읽으면 `📝 기록하기` → 표(도전·명령 카드 순서·도착한 곳·성공 O/X = 활동지 1번).
- ② 블록 → `👀 화면에서 해 보기`(로봇 없이) 또는 `▶ 알티노 실행`(1초 준비, coral `■ 멈춰`) → 실행 중인 블록이 노랗게, 지도에 자취. 도착점이면 `success` + 되풀이 규칙 문장, 길 밖·다른 칸이면 `fail` + 어느 블록인지. 알티노로 완주하면 `⭕ 도착했어요`/`❌ 못 갔어요` — ❌ 면 "순서는 맞아요, 한 칸 맞추기를 해 봐요"(순서 실수와 이동 오차를 나눔). 오른쪽 위 `📏 한 칸 맞추기`: 한 칸 시간 −/+ 와 `↑ 한 칸 해 보기`, `■ 멈춰`. 실행 중 돌기 블록 → 창(도움 그림 · '알티노를 왼쪽으로 돌려주세요.' / '…오른쪽으로…' · `✅ 돌렸어요` · `■ 멈춰`). `👀 화면에서 해 보기`는 창 없이 지도에서만 돈다.
- ③ `미션 1~3` 칩(해결하면 ✓) → 버그 순서로 시작 → 실행·고치기 → 도착하면 해결. 표(미션·버그·고친 순서·해결 = 활동지 3번).
