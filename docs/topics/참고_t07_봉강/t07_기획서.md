## 5. 화면 흐름
- ① 도트 문제 읽기: 기호 고르기 → `▶ 문제 보여 주기`(도트에 차례로 표시, 다시 보기 가능) → 답 쓰고 `확인` → 맞으면 화면에 식 공개, 틀리면 한 번 더 기회, 두 번 틀리면 답 공개 → `다음 문제 →` / `레이스 하러 가기 →`
- ② 연산 레이스: 초3/초4 문제 고르기 → `▶ 레이스 출발`(start 신호 + 준비… 출발! 1초) → 문제 풀기(틀려도 감점 없음, `이 문제 넘기기`) → 10칸 또는 3분이면 ③으로. `■ 멈춰` 는 레이스 중 늘 보인다(멈추면 기록 없이 처음부터)
- ③ 결과 보기: 별 · 모둠 이름 · 가장 좋은 기록 → `다시 하기` / `처음부터`(확인창)
