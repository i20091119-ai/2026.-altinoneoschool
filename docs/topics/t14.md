## 2. 배움 목표
- 지도의 방위(위쪽 = 북)와 그림 기호를 읽고 장소의 위치를 말할 수 있다.
- 긴 길을 구간으로 나누어 블록으로 순서를 세우고, 경유지마다 🚩 힌트를 남길 수 있다.
- 예상한 길과 실제 움직임을 비교해 틀린 구간의 블록을 고칠 수 있다.

## 5. 화면 흐름
- 단계 `① 지도 읽기 ② 경유지 1곳 ③ 탐험 시험`.
- ① 문제 6개(방위 버튼 / 지도 누르기), 도트 힌트 미리 보기, `↺ 다시 풀기`.
- ②·③: 코스 칩(연습 1·2 / 탐험 A·B·C), 구간 안내, 블록 팔레트(⬆ 앞으로 · ↰ 왼쪽 꺾기 · ↱ 오른쪽 꺾기 · 🚩 힌트, 12개까지), `⌫ 하나 지우기`·`모두 지우기`(확인창), `▶ 실행` / `■ 멈춰`.
