## 5. 화면 흐름
- 단계 표시 `① 알티노의 문제 읽기 ② 알티노 답안지 채점하기 ③ 연산 레이스` — 단계를 바꾸면 움직임·도트 연출을 멈춘다.
- ① 학년 칩(3학년·4학년) → `▶ 문제 보기`(도트 연출, 그동안 화면엔 식이 안 보임) · `다시 보기` → 답 입력(`<input type=number inputmode=numeric>` + `확인`, Enter 도 됨) → 맞으면 식과 답이 보이고 `다음 →`, 틀리면 격려 문구 뒤 다시 풀기. 오른쪽에 이번 차례 역할 카드(1번·2번·3번 친구 → 식 읽기·답 입력·확인, 문제마다 돌아감)와 푼 문제 목록(식·내 답·O·X).
- ② 알티노 시험지 1~6번 카드 → 카드 누르면 도트로 `수 → 기호 → 수 → = → 알티노의 답` → `O 맞아요` / `X 틀려요` → 채점이 틀리면 다시 계산하라는 문구(처음 채점만 점수로 셈) → 틀린 답을 X 로 맞게 채점하면 바른 답 입력(도트 ☺) → 가르쳐 줄 말 고르기(까닭 3개 중 맞는 것, 또는 직접 쓰기, 도트 ♥) → 6문항 끝나면 '내 채점이 맞은 수'와 '가르친 문항 수'.
- ③ `▶ 준비… 출발!` → 1초 준비 → 3:00 타이머, 큰 문제 카드 + 입력, 정답 수 큰 숫자. 맞히면 `success` + 한 칸 전진(여러 문제를 빨리 맞히면 차례로 한 칸씩) + '다음 풀이자 차례', 틀리면 `fail` + 같은 문제를 다시. `🃏 도움 카드 (2)` 는 그 문제의 힌트(곱셈 = 몇 번 더하기, 나눗셈 = 곱셈으로 거꾸로). coral `■ 멈춰` 는 달리는 동안 보임 — 도중에 멈추거나 단계를 바꾸면 그 라운드는 기록하지 않는다. 시간이 끝나면 정답 수·배지 → `▶ 2라운드 하기`. 두 라운드가 끝나면 `처음부터`(확인창).

## 10. 열린 질문
- 도트 기호(× ÷) 그림이 학생에게 잘 읽히는지 실기 확인 — × 는 실패 아이콘(✗, 8칸 가득)과 헷갈리지 않게 가운데 4칸으로 작게 그렸다
- 레이스 '한 칸' 거리(300×1초)가 레인 길이(2m) 안에 드는지 — 12문제 ≈ 1.5m 예상
- 레이스 시간은 저장값 `altino.t07.raceSec`(기본 180초)로 바꿀 수 있다(시험·현장 조절용, 화면 버튼은 없음)
