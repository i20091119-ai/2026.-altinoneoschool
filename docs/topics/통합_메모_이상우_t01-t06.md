## t02 버그 (수정 포함)

② 속도의 비밀 찾기에서 `■ 멈춰` 를 누르면 로봇은 서지만 화면이 '달리는 중'에 멈춰 `▶ 3초 달리기` 가 다시 안 나왔다.
원인: `kit.stop()` 은 실행 세대를 올려서 `onRunEnd` 를 부르지 않는다. → `stopBtn` 에서 `endRun()` 을 직접 부름.
(t01·t03~t06 도 같은 이유로 멈춤 버튼에서 화면을 직접 되돌린다.)
※ kit 쪽에서 `stop()` 때도 `onRunEnd` 를 부르게 바꿀지는 통합 담당 판단(바꾸면 13 문서·smoke·mutation 같이).

## 통합 담당에게 요청 (01 §5)

1. **공용 데이터(t15 학예회에서 다시 쓰기, 2026-10-20 결정)**
   - t03 표정 4장: `altino.t03.faces` = `{ praise|pencil|noise|fall: { feel, bytes[8] } }`
   - t05 신호표: `altino.t05.signals` = `{ 안녕|고마워|조심해|따라와: ['ls','ll','hs','hl', …] }` (l=빛 15, h=경적 42, s=짧게 0.3초, l=길게 0.9초, 사이 0.3초)
   - (후보) t04 바꾼 가락: `altino.t04.mine` = `{ song, notes: [{ i: 0~7, l: 길게? }] }`
   - 앱끼리 서로 저장값을 읽지 않는 규칙(10 §6)이 있으니 공용 키나 kit 기능으로 열어 줄 것.
2. **kit 기능**: '소리만 끄기'(`kit.beepOff()` 등). 지금 t04 ③ 은 손을 떼면 `kit.stop()` 으로 끈다(바퀴를 안 써서 부작용 없음).
3. **LED**: `kit.stop()` 이 LED 를 끄지 않는다. t05 는 앱에서 `kit.led(0)` 을 직접 부른다.
