## 2. 배움 목표
- 배운 내용으로 문제·보기·정답·까닭을 갖춘 퀴즈를 만들 수 있다.
- 친구들을 바라보며 또박또박 자신감 있게 퀴즈를 출제할 수 있다.
- 답 잠금 규칙을 지키며 골든벨 대회에 참여하고 결과에 승복할 수 있다.

## 5. 화면 흐름
- 단계 표시 `① 골든벨 연습 ② 우리가 내는 퀴즈 ③ 알티노 골든벨 대회` — 단계를 바꾸면 움직임을 멈춘다.
- ① 연습 문제(PPT 와 같은 5개, 문제 글도 보임) → 답 버튼(O·X 또는 ①②③) → `🔒 답 잠금`(그 뒤 답 못 바꿈) → `정답 확인` → 맞으면 `⭕ 맞혔어요 → 한 칸 전진`(한 문제에 한 번), 틀리면 `다음 문제 →`. 오른쪽에 활동지 1번과 같은 표(번호·우리 모둠 답·정답·맞힘)와 `■ 멈춰`·`처음부터`.
- ② `O·X 퀴즈`/`고르기 퀴즈` 탭 → 문제·(보기 3개)·정답·까닭 입력(빈 칸 안내) → 오른쪽 '크게 보며 문제 읽기'에 크게 보이고 `정답 공개`로 정답·까닭을 보여 준다.
- ③ 왼쪽: 레인(결승선 🔔까지 칸, 🚗 위치), 결승선·한 칸 시간 조절(라운드 중에는 결승선 못 바꿈), 1라운드·2라운드 기록, `■ 멈춰`·`라운드 끝내기`(확인창)·`처음부터`(확인창). 오른쪽: n번 문제 — 답(O X ① ② ③ ④) → `🔒 답 잠금` → 정답이 공개되면 `⭕ 맞혔어요`/`❌ 틀렸어요`, `🎤 우리 모둠 문제예요(사회자)` 는 그 문제를 건너뛴다. 전진 도중 `■ 멈춰` 로 끊기면 그 칸은 세지 않는다(다시 누를 수 있음). 결승선에 닿으면 골든벨 → 라운드가 끝난다.
