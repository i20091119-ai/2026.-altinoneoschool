# 알티노 로봇학교 앱 — 개발 과정 (2026-10-02 ~ 2026-11-26)

32차시 학교자율시간 수업용 태블릿 앱. 15개 주제 앱(t01~t15) + 로봇학교 첫 화면 + 체험관.
저장소 `i20091119-ai/2026.-altinoneoschool` · 웹 https://i20091119-ai.github.io/2026.-altinoneoschool/school.html

**태블릿 앱(APK) 받기**: https://github.com/i20091119-ai/2026.-altinoneoschool/releases/latest → `altino-v1.0.xxxx.apk` 를 눌러 내려받아 설치.
이미 깔린 태블릿은 앱 안 `🔄 업데이트 확인`. 웹 주소(로봇학교 첫 화면)에서도 오른쪽 위 `📥 앱(APK) 받기` 로 같은 곳에 간다.

## 3. 일하는 방식

- 작업 브랜치 → PR → APK 빌드 확인 → main 합침. main 에 합치면 GitHub Actions 가 APK 를 만들어 Release `v1.0.<1000+실행번호>` 로 올리고, 웹(GitHub Pages)도 바뀐다.
- 태블릿은 앱 안 `🔄 업데이트 확인`(로봇학교 첫 화면·체험관 홈)으로 받는다. 기록(성장기록부 등)은 태블릿 안에 남는다.
- 공동저자는 앱 파일만 낸다. 공용 파일은 통합 담당만 고치고, 바꾸면 지문을 다시 찍는다(`node tools/check_contribution.mjs --snapshot`).
- 합치기 전 확인: `tools/check_contribution.mjs tNN`, `tests/smoke.mjs tNN`(공통 안전 21개), `tests/tNN.mjs`, `tests/pages.mjs`, `tests/school.mjs`, `tests/mutation.mjs`(안전 규칙을 일부러 깨면 시험이 잡는지), `tests/lite.mjs`·`tests/frames.mjs`(통신 프레임).
- 공동저자 zip 에 함께 온 공용 파일 복사본은 옛 판이라 가져오지 않는다. 웹 미리보기용 '데모 도구'는 뺀다.

## 4. 주요 문제와 해결 (자세히는 `dev-guide/04_시행착오_사례집.md` #40~#48)

| 문제 | 원인 | 해결 |
|---|---|---|
| 웹 배포 실패 | Pages 배포 환경이 main 을 허용 안 함 | 저장소 설정에서 main 허용, 배포는 main 에서만 |
| APK 를 깔면 체험관만 나옴 | 시작 주소가 home.html | 시작 화면 = 로봇학교 |
| 업데이트가 옛 저장소를 봄 | 저장소 이전 | 업데이트 주소 변경, 빌드번호 1000+ |
| 라이트가 연결·끊김 반복, 안 움직임 | 네오 프레임만 보냄 | 라이트 22바이트 프레임, 긴 프레임 나눠 쓰기 |
| 폰에서 오른쪽 잘림, 아래 버튼(■ 멈춰) 안 보임 | 시스템 바 밑까지 그림, 1280×800 기준 화면 | 시스템 바 여백, 높이 720 미만이면 페이지 축소 |
| '멈춰' 뒤 화면이 '달리는 중'에 멈춤 | kit.stop 이 onRunEnd 를 안 부름 | kit 1.1 에서 stop 이 불빛도 끄고 onRunEnd 호출 |
| 격자에서 왼쪽·오른쪽으로 못 돎(t11·t14) | 앞바퀴 조향이라 제자리 회전 불가 | 손으로 돌리기 + 도움 그림 창 |
| 구형 알티노면 안 움직일 것 | 이름이 ALTINO-L 이 아니면 전부 네오로 보냄 | 세 기종 프레임, 답이 없으면 다른 기종 차례로 시도·로봇별 기억 |
| 라이트에 불빛 15 → 깜빡이까지 다 켜짐, 배터리 늘 빨강 | 기종마다 LED·배터리 뜻이 다름 | 앱은 네오 뜻으로 쓰고 기종별로 바꿔 보냄, 라이트·구형 배터리는 % |

## 6. 실기로 아직 확인 안 한 것

- 라이트·구형 프레임으로 우리 앱에서 움직임·센서·불빛(구형은 캠프 앱에서 확인됨).
- 기종 찾기가 실제 로봇에서 맞는 기종으로 자리 잡는지.
- t05 불빛(깜빡이·브레이크) — ④ LED 점검으로 1·2·4·8·16·32·64·128.
- 도트 방향(t01·t03·t06), 8음 음높이(t04), 손 거리 기준·조향 방향(t06).
- t10 속도 250 이 끝까지 굴러가는지(네오 최저 구동 300 이라는 기록이 있음).
- t11·t14 한 칸 시간 기본값(1.0초), t12 꽁무니 센서 ir6, t13 태블릿 🎤.
